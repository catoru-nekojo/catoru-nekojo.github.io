# Other Projects
To run these, you'll have to;
1. Download the zip by clicking the Green code button top-right
2. Click "Download ZIP"
   <img width="417" height="348" alt="image" src="https://github.com/user-attachments/assets/030898c8-e0a0-4677-8d31-7dd2c027d55c" />
3. Navigate to your downloads folder
4. Right-click the ZIP and Extract all
5. Double-click main.py

Having Python Installed on your computer is **required**. To download and install python. Follow the steps [here](https://www.python.org/downloads/)
